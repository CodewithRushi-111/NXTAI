# AI Workspace PRD + Reference Pack

## How to use this pack

1. Extract this folder into `C:\Users\rishi\Desktop\ai-workspace` (the root of the already-created Next.js project). If Windows asks to merge folders, keep the existing app files. The pack adds `PRD.md`, `docs/`, and `reference-screens/`; it should not replace `src/`, `package.json`, or other app files.
2. Open the whole `ai-workspace` folder in Antigravity.
3. Give Antigravity the first-task prompt in `docs/ANTIGRAVITY_FIRST_TASK.md`.
4. Ask it to read `PRD.md` fully and inspect every screenshot in `reference-screens/` before editing.
5. Allow only Phase 1 (high-fidelity UI shell/pages) for the first pass. Do not connect provider keys or run live calls yet.

The screenshot images include some recording/OS overlays and browser chrome; do not recreate those overlays as app features. Use the app surface only as the layout reference.

Keep the existing `briefproof` folder untouched. Do not add real API keys to this project at this stage.
